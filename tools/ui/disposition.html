Glisser un élément pour le déplacer ; Maj+clic ou un cadre tiré sur le fond pour en choisir plusieurs.
Le carré jaune change la taille (boutons, vue de la ville) ; le rond bleu agrandit tout l'élément, par demi (×1, ×1,5, ×2… : les pixels restent nets) ; Ctrl sur le carré jaune : agrandir aussi.
Suppr retire les éléments choisis de l'écran ; cocher leur case dans la liste les remet.
←↑→↓ : d'un cran de la grille, Maj : d'un pixel (2).
Les bords et les milieux s'aimantent à ceux des autres éléments (lignes rouges) ; Alt en glissant : sans aimant.
Tout s'enregistre seul dans le jeu. « Voir dans le jeu » montre le vrai écran (une dizaine de secondes).
