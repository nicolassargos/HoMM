# Crédits des images

Les images de ce dossier ont été générées avec [Retro Diffusion](https://www.retrodiffusion.ai/)
(API, styles `rd_tile__single_tile`, `rd_tile__tile_object` et, pour les cadres et boutons, `rd_plus__ui_element`), à partir des descriptions de
`tools/art/assets.json`, puis choisies parmi plusieurs candidats.

La police de l'interface, Pixel Operator (Jayvee Enaguas), versions HB 8 et HB, est dans le domaine public (CC0 1.0) :
voir `godot/fonts/PixelOperator-LICENSE.txt`.
